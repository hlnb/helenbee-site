## Writing New Posts

### File Naming Convention

```bash
YYYY-MM-DD-title-slug.md
# Example: 2024-11-24-building-modern-personal-site-with-11ty.md
```

### Front Matter Template

```yaml
---
layout: writing.njk
title: Your Post Title
description: Brief description for SEO and social sharing
date: YYYY-MM-DD
category: technology
tags:
  - technology
  - web development
  - 11ty
image: /assets/images/post-image.jpg
excerpt: Brief excerpt for listings and social sharing
---
```

### Required Fields

- `layout`: Template to use (writing.njk for blog posts)
- `title`: Post title
- `date`: Publication date
- `description`: SEO description
- `category`: Primary category (matches category directory structure)

### Optional Fields

- `tags`: Array of relevant tags
- `image`: Featured image path
- `excerpt`: Custom excerpt (defaults to first paragraph if not provided)

> Tip: The CMS now includes an **Excerpt** field—fill it in so feeds, listings, and social previews use your curated summary instead of the opening paragraph.

## Categories and Tags

Use these primary categories in front matter and the local Sveltia editor:

| Stored value | Display label | Use for |
| --- | --- | --- |
| `lived-experience` | Lived experience | Personal accounts of service, recovery, identity and resilience |
| `reflection` | Reflection | Reflective essays, philosophy, journalling and seasonal reflections |
| `technology` | Technology | Web development, digital tools and connected health |
| `creative` | Creative & craft | Knitting, making and creative practice |

Use lowercase stored values. Craft and Creative share `creative`; Philosophy
belongs under `reflection`. The former `Reflection` spelling is also
`reflection`. Keep specific subjects such as knitting and Stoicism in tags.
An article can cross themes; choose its main intent rather than moving all
mentions of craft or technology out of lived experience.

Display labels are defined in `src/_data/writingCategories.json`; keep the
category choices in `public/admin/config.yml` aligned with them. Category
changes do not change article filenames or URLs.

The Writings index provides jump links to each category and shows up to six
articles per category page. Every category uses the same pagination; page
buttons appear only when there are more than six published articles. Each
category keeps its own page selection. Changing pages announces the visible
article range and returns keyboard focus to the category heading.

Pagination is provided by `assets/js/writings-pagination.js`. Without
JavaScript, all published articles remain visible and the jump links still
work. To verify category navigation and pagination after changes, run
`npm run build` followed by `node --test tests/*.test.cjs`.

Home page Latest Writings and the Writings index both check `publishedDate`
using Australia/Perth time. A future date keeps a card out of both listings
until a build runs on or after that time. The daily rebuild workflow in
`.github/workflows/vercel-scheduled-rebuild.yml` is scheduled for 09:05 AWST
and requires the `VERCEL_DEPLOY_HOOK_URL` repository secret. Its presence
and successful runs must be verified before relying on automatic publication.

## Books Workflow

Book pages live in `src/books/` and now use the dedicated `layouts/book.njk` layout.

### Book Front Matter

Each book can include:

```yaml
layout: layouts/book.njk
title: "The Body Keeps the Score"
author: "Bessel van der Kolk"
dateRead: 2024-03-10
rating: 5
review: "Short summary of why the book mattered."
coverImage: "/assets/images/books/body-keeps-score.jpg"
tags: ["books"]
bookCategory:
  - trauma
  - ptsd-recovery
comments: "Optional shorter note shown as My Notes."
```

### Adding Reflections

- Add your longer reflections directly in the Markdown body below the front matter.
- The book layout renders that body under the heading `What I Found Helpful`.
- If the body is empty, the page shows a placeholder prompt instead.

### Book Categories

- Use `bookCategory` to group books by topic for future browsing and filtering.
- `bookCategory` accepts either a single string or a list, but a list is preferred.
- Example:

```yaml
bookCategory:
  - stoicism
  - mindfulness
  - habits
```

### How Categories Are Used

- `collections.books` is the main Eleventy collection for all book pages.
- `collections.booksByCategory` groups books by `bookCategory`.
- The `/reading/` page automatically shows topic links once books have been categorised.
- Individual book pages display their assigned topics in the summary panel.
